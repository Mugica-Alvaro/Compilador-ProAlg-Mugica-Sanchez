#Instrucciones de Uso (Makefile)

El proyecto incluye un Makefile automatizado con los siguientes comandos:

#1. Ejecución introduciendo la entrada por teclado: 
make

#2. Ejecución utilizando como entrada el primer programa de prueba (programa1.alg):
make run1

#3. Ejecución utilizando como entrada el segundo programa de prueba (programa2.alg):
make run2

#4. Ejecución utilizando como entrada el segundo programa de prueba (programa3.alg):
make run3

#4. Borrar el ejecutable y los archivos generados durante la compilación
make clean
